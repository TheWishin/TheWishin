### 🥊 Main quest: Tekken, native and online

**[T5DR Online](https://github.com/TheWishin/T5DROnline)** — *Tekken 5: Dark Resurrection* (PS3) running natively on Windows
through static recompilation, playable online against friends.

- Rollback netcode with frame-exact state checks; 0 desyncs is the bar for every release
- Lobby, rooms, friends, ranked with rank emblems, tournaments, replays and spectating
- Up to 4K internal resolution, training overlay with frame data, pad and keyboard bindings
- US and EU versions play each other online
- Built from your own PSN purchase on your own PC: one button, everything included

**[Tekken 4 Recomp](https://github.com/TheWishin/Tekken4Recomp)** — *Tekken 4* (PS2, USA) recompiled to a native Windows
program with the same online stack: lobby, ranked, rollback. Built from your own disc image, no BIOS, no download.

### 🧰 The launcher

**[OpenRecomp-FGC](https://github.com/TheWishin/OpenRecomp-FGC)** — one launcher for all of them.

| | What it does |
|---|---|
| 🎮 Library | Tekken 5 DR and Tekken 4 side by side, pad-first, works from the couch |
| 🔧 Build | Picks your files, builds the game, shows exactly what happens — nothing to install |
| 🌐 Online | Lobby, quick match, ranked, friends, rooms, live stats |
| 🔄 Updates | Signed releases, "Update all" updates the launcher first and then your games |
| ⌨️ Bindings | Per-player pad and keyboard bindings for every game |
